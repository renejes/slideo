# .loom — Slideo Architektur-Spec

Knoten-basierte Architektur-Karte (loom-spec). **Authored**, nicht aus Code generiert —
Mensch (Browser-Editor) oder KI (MCP/JSON) pflegen sie, `code_refs` ankern an echte Quelle.

- `node-types.json` — Knoten-Vokabular (Schichten-Typen).
- `diagrams/overview.flow.json` — Architektur-Übersicht (Schichten + Kernmodule + Datenfluss).

Ansehen/Editieren: `npx loom-spec view` → http://localhost:7777
Drift prüfen: `npx loom-spec validate`
